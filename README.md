# Wanderlust 🌍✈️

**Travel Around the World**

Wanderlust is a web application designed to inspire and help travelers explore destinations around the world. Plan your adventures, discover new places, and share your travel experiences.

## ✨ Features

- 🌐 Explore destinations worldwide
- 📍 Search and filter travel locations
- 🗺️ Interactive maps and location details
- 📝 Create and manage travel itineraries
- 💬 Share travel experiences and reviews
- 🎨 Beautiful and responsive user interface
- 📱 Mobile-friendly design

## 🛠️ Technology Stack

This project uses a modern web development stack:

- **Frontend:**
  - JavaScript (48.5%) - Core application logic
  - EJS (30.8%) - Server-side templating
  - CSS (20.7%) - Styling and layout

- **Architecture:** Node.js with Express.js backend

## 📦 Installation

### Prerequisites

- Node.js (v12.0 or higher)
- npm (v6.0 or higher)
- Git

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/anjaliOfficialcoll/Wanderlust.git
   cd Wanderlust
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment variables**
   - Create a `.env` file in the root directory
   - Add necessary configuration variables (database URLs, API keys, etc.)

4. **Start the application**
   ```bash
   npm start
   ```

5. **Access the application**
   - Open your browser and navigate to `http://localhost:3000`

## 🚀 Usage

### Getting Started

1. Open the application in your web browser
2. Browse through available travel destinations
3. Click on any destination to view detailed information
4. Create a new itinerary or add destinations to your favorites
5. Share your travel experiences with the community

### Key Features

- **Search Destinations:** Use the search bar to find specific locations
- **View Details:** Click on any destination to see photos, reviews, and travel tips
- **Create Itineraries:** Plan your trip with the itinerary builder
- **Save Favorites:** Bookmark destinations for later reference
